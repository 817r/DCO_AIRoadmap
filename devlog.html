v0.4.146 Dev build OCTOBER 23, 2026 · not on the Workshop yet

Soldiers who break, and leaders who hold them together.

Morale and panic were rebuilt, and a new Leadership trait decides how much a squad can take before it comes apart. The commander learned to keep attacking instead of consolidating, and to stop coming from the same direction every time.

Soldiers

  • Leadership trait: Poor, Average, Good, Inspiring
  • Being hit adds stress; squad support is capped so panic can happen
  • Panic varies: dash to cover, flatten, run to a calm buddy, wild burst
  • Cover selection rewritten; prone watchdog stands blind soldiers up
  • Civilian mode back, with per-faction caution

Commander

  • Aggressive doctrine is relentless — only pulls back below 70% strength
  • Defensive holds its garrisons and retakes what it loses
  • Approach axis varies; staging points expire
  • Reserves get real jobs: QRF, observation posts, link patrols
  • Five minutes of stalemate forces a different tactic

Squads & vehicles

  • Evasive posture: escape fast, hold fire, hide, lurk back
  • CQB clears the room nearest the enemy first; windows suppressed during the stack
  • Soldiers walking for ammo stop and fight when an enemy is close
  • Speed limit and AI Simulation now set per squad
  • A dead gunner is ejected so the turret can be re-manned

Settings

  • Nine built-in presets, six global and three per faction
  • Twenty-six new settings, each with help text
  • No suppression through walls
  • Console spam gone, all script warnings cleared
v0.4.145 Latest on Workshop OCTOBER 12, 2026 · v0.4.144 → v0.4.145

Everything opened up.

The update the mod had been building toward: a settings window instead of hunting through attribute categories, a server config you can actually read, and a published API so other addons can build on DCO instead of patching it.

Settings window

  • 839 settings across 16 folders, opened with F2
  • Simple, Advanced and Expert views
  • Search, favourites, per-setting help, Beta tags
  • Per-faction values on top of the global ones

Modding API

  • Fifteen events to subscribe to
  • Settings at four scopes; AI state read-only
  • Every write logged under the calling mod's name
  • Victory component for mission end conditions

Server config

  • A folder of JSON files instead of one long file
  • 535 tuning keys, each with a default and a range
  • Old single-file configs split automatically
  • Structured logs and a per-run report

Behaviour

  • Combat context: range bands and environments
  • Indoor navigation for room-to-room movement
  • Garrison and CQB waypoints in command mode
  • Commander intent overlay on Ctrl + I
v0.4.142 SEPTEMBER 28, 2026 · v0.4.137 → v0.4.142

Now you can give the orders.

The AI commander can be placed straight from the Game Master editor, and players can talk to it: report contacts, request support and call fire missions from the command menu.

Player command

  • Report contacts: team, squad, platoon, vehicle, armor
  • Request suppression, support, flanks or armor
  • Call transport, extraction and MEDEVAC
  • Fire missions: HE, smoke and illumination v0.4.142

Commander from the editor

  • Place an AI Commander from the content browser v0.4.137
  • Assign groups and vehicles to it v0.4.138
  • Commander spawns and feeds its own units
  • Seventeen DCO attribute categories in the editor

In the dev build

  • Garrison system: buildings held by slot, with release triggers
  • Room-by-room building clearing
  • Logistics and cross-group medics, including MEDEVAC
  • Thirteen named commander tactics, ambushes and counter-battery

Under the hood

  • Codebase reorganised — 188 scripts, 47k lines added
  • Terrain cache for commander decisions
  • LOD and update budgets for large AI counts
  • Benchmark logger for performance testing
