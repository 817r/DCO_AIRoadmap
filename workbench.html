Set up DCO in a mission

Eight steps to wire DCO into a mission you are building in the Arma Reforger Workbench. Every value here was read out of the mod's own prefabs and configs, so the defaults match what you will actually see.

Before you start: you need an addon that lists 5EDAAE0D3CC60D6B (DCO_AI) as a dependency, and a world with a soldier navmesh. Both are ordinary Reforger modding. In a hurry? The same setup takes five minutes in Game Master, it just does not ship with the mission.

1

What every scene needs

Four things have to exist before any DCO entity does anything.

NeedWhat to placeWhy
Game modePrefabs/MP/Modes/GameMode_Base.etDCO overrides this prefab to add DCO_GlobalAIComponent, where every global setting lives. The vanilla GameMode_Editor_Full.et works too.
AI worldPrefabs/AI/SCR_AIWorld.etDCO overrides it to add formations and the cover manager.
Faction managerSCR_FactionManagerWithout it a commander's faction list is empty.
Commander managerPrefabs/Commander/CommanderManager.etCommanders and objectives register with it.
The one that catches everyone. Only the Game Master commander prefab spawns a manager for you. The Workbench prefabs do not, so a mission with commanders and no CommanderManager looks completely correct and does nothing at all.
2

Place the commanders

One per AI side. Position does not matter — a commander is a brain, not a unit. Drop in Prefabs/Commander/US_Commander.et (it is based on Commander.et) and open AICommander_AlgorithmComponent.

FieldSet toNotes
Faction KeyRequiredUS, USSR, FIA… Empty and it rejects every group; the start-up check logs faction=EMPTY.
Commander UIDRequiredA short unique name. Spawners, groups and objectives all refer to the commander by it. Empty, duplicated or containing ; or | and DCO renames it to <FACTION>-N.
Commander ModeBalancedOffensive only attacks, Defensive only defends. It never changes by itself.
Think Interval150 s in the prefabThe script default is 30 s — the shipped prefab raises it. Lower it for a small test mission or you will wait a long time between decisions.
Delay First Iteration60 sGrace period before the first decision.
Reinforcement Stock−1Men available to spawners. −1 is unlimited; the examples use 60.
The attribute categories are numbered. Commander 01, 02. Timing, 04. Attack, 06. Staging & Routes, 08. Defend & Garrison, 15. Player Tasking — so the panel always lists them in the same order and you can tell someone "it is in 04".
3

Place the objectives

Prefabs/Commander/Commander_Objective.et, one per thing worth fighting over. The prefab ships with base value 70 and radius 145 m — the script defaults behind it are 50 and 30 m.

FieldDefaultNotes
Name—Max 32 characters. It appears in logs, overlays and briefings; an unnamed objective is painful to debug.
Radius145 m (prefab)A town 100–150 m, a farm or crossroads 40–60 m. Units inside count toward control.
Initial Owner Commander UIDEmptyThe Workbench name for what Game Master calls Controlled By. Empty means neutral. The old "Set Captured by Commander" is only a fallback.
Base Value70 (prefab)0–100. How badly commanders want it.
Capture Hold Duration60 sControl moves at 100 ÷ this per second, scaled by how many are inside (full speed at 8) and how clearly one side outnumbers the other.
Destroy TargetsEmptyWorkbench only. A list of entity names, which Game Master has no way to enter — so a Destroy objective can only be built here.
An objective only moves while somebody is working on it. Control advances only if a commander is actively planning it. One that no commander handles never changes hands, however many soldiers stand in it.
4

Put groups under a commander

A group built on Prefabs/AI/Groups/Group_Base.et already carries the DCO components. What it will not do is join a commander by itself — and this is the second most common reason a mission does nothing.

On the group, open DCO_GroupUtilityComponent, category Commander:

SCR_AIGroup USSR_Garrison : "…/Group_USSR_RifleSquad.et" {
 components {
  DCO_GroupUtilityComponent {
   m_bAutoAssign 1          // Auto Assign
   m_sDedicatedCo "Volga"   // Dedicated Co — the commander UID
  }
 }
}
FieldDefaultEffect
Auto AssignOffJoin a commander when the scenario starts. Off means the group fights with DCO behaviour but never receives orders.
Dedicated CoEmptyThe commander UID to join. Empty means a random commander of the same faction. It retries roughly twelve times before giving up with a log line.

Vehicles have the same pair, so a transport truck can belong to a commander too.

5

Static waypoints

This is the step that works differently from Game Master. A waypoint is a separate entity with a name, and the group references that name.

  1. Place Prefabs/AI/Waypoints/AIWaypoint_Garrison.et where the group should hold, and give the entity a name — say WP_Garrison.
  2. On the group, add that name to Static Waypoints.
DCO_GarrisonWaypoint WP_Garrison : "…/AIWaypoint_Garrison.et" {
 coords 3150.9 12.2 2871
}
SCR_AIGroup USSR_Garrison : "…/Group_USSR_RifleSquad.et" {
 m_aStaticWaypoints {
  "WP_Garrison"            // by entity name, not by reference
 }
}
Do CQB does not work as a static waypoint. It is not picked up from Static Waypoints — give it at runtime or from Game Master instead. Garrison is the one that works this way.
Buildings are searched within the waypoint's completion radius, minimum 30 m and 40 m in the prefab. With no building the group takes field fighting positions; failing that it behaves like a vanilla Defend waypoint.
6

Reinforcements and logistics

Optional, but this is what turns a skirmish into an operation.

Commander Spawner

Prefabs/Commander/CommanderSpawner.et, placed behind the side's line.

FieldExampleNotes
Target / Commander UIDSPECIFIC_UID, "Viking"Or weakest / nearest of a faction.
PresetCommander on callUse this for an attacker. Counterattack wave only fires when an objective your side holds is lost, so on an attacker that owns nothing it can never trigger.
Groups (force pool)rifle squad ×2, fire team ×1Weighted entries. Leave empty for random groups from the faction catalogue.
Take From StockMENDraws from the commander's Reinforcement Stock.
Safe Radius300 m (example: 150)Nothing spawns while a player or enemy is inside it.
Cooldown300 s (example: 60)Between trigger spawns.

Logistics hub

Prefabs/Commander/LogisticsHub.et with one field, Hub Faction. But a hub on its own does nothing:

  • A transport team — any group of at most three men in one unarmed vehicle with a driver and four free cargo seats becomes one automatically, or tick Dedicated Transport on a group.
  • For resupply, that vehicle has to be an ammo truck. A normal transport truck cannot resupply.
  • An ammo source at the hub — an arsenal box or ammo truck. Low-ammo squads within 200 m then restock by themselves.
Without a transport team every resupply, MEDEVAC and extraction request waits five minutes and is then cancelled.

Mortars

Place a mortar and a group of up to four whose leader stands within 40 m of it, assigned to a commander. Within about a minute, while the group is untasked, it becomes a mortar team on its own.

7

Give the mission an end

Add DCO_VictoryComponent to the game mode entity — or to any spare entity, which keeps the vanilla game mode untouched. Rules combine; the first faction to meet any active one wins.

RuleDefaultWins when
Hold Count0 (off)A faction holds at least this many objectives.
Hold All PrimaryOffA faction holds every objective marked Primary.
Hold Objective + MinutesEmpty, 5One named objective held that long without a break.
Enemy Stock EmptyOffEvery enemy commander has used up its soldier stock.
Grace / Check Seconds60 / 5Nothing is checked before the grace period, then at that interval.
Pair two rules for an asymmetric mission. Hold All Primary plus Enemy Stock Empty gives the attacker a way to win by taking ground and the defender a way to win by bleeding the attacker dry.
8

Test, then publish

What a healthy start looks like

TimeWhat you should see
T+7 sEvery squad has joined its commander.
T+20 sThe start-up check writes its block. setup_check_done warn=0 means the scene is sound.
T+30 sObjectives that failed the first navmesh test are re-checked, for tiles that had not loaded.
T+65 sThe first orders go out — after that, one decision cycle apart.
Not in the scenario list? That is the mission header, not DCO — a world with no Missions/*.conf pointing at it never appears. Point it at your world and use the Game Master systems config, which is what gives you the editor to watch a DCO mission with.

Tools you get in the Workbench

ToolNotes
Intent overlayCtrl + I. Always available in Workbench play mode, where a Game Master has to enable it first.
Profiling & censusBoth turn on automatically in Workbench play mode.
LogsDocuments\My Games\ArmaReforgerWorkbench\profile\DCO\Logs\, one folder per session.
Start-up checksGrep dco.log for setup_check. It catches the missing faction, the missing UID, an objective nobody handles and a missing navmesh.

Before you call it done

  • setup_check_done warn=0 on a clean run.
  • Every squad joins at T+7 s — none left behind by a missing Auto Assign.
  • Each side starts with the objectives you intended.
  • Objectives sit on navmesh, including the ones at the map edge.
  • Attacker spawners use a preset that can actually trigger.
  • A think interval that suits the mission size, not the 150 s the prefab ships with.
  • Your mission lives in your own addon — you have not edited DCO_AI itself.

Stuck on a step?

Bring your dco.log to Discord — the setup_check block usually names the problem outright.
