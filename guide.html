How to use DCO_AI

DCO_AI runs on vanilla AI with no setup at all — just load the mod. Everything below is optional: commanding AI as a player, running an AI commander from the editor, garrisoning buildings and tuning behaviour for your server.

Getting started

DCO_AI replaces how vanilla AI thinks. Any AI already in your scenario picks up the new behaviour — you don't have to rebuild missions or place special units.

  1. Subscribe to DCO_AI Reforger on the Arma Reforger Workshop.
  2. Enable it as a mod for your scenario, or add it to your server's mod list.
  3. Load any scenario with AI. That's it — soldiers now suppress, use cover, dodge and react as a group.
  4. Want a commander, player orders or garrisons? Continue below.
Version note. Features marked Dev build on the roadmap are written but not in the public Workshop build yet. Everything in this guide that is live is marked with its version.

For players

You talk to the AI commander through the same group command menu you already use to order your squad. Point at a place or an enemy, open the menu and pick an order.

Your own HUD

DCO adds its own tab in the game settings, where each player controls their own display: where the order banner sits, its size and offset, whether contact toasts appear, how long they stay, their scale and sound, and the map overlay palette. The tab also has Test notifications and Reset DCO.

For Game Masters

An AI commander turns loose groups into an operation: it takes objectives, defends what it holds, dispatches QRF, keeps reserves and answers player requests.

Put a commander in the field v0.4.137

  1. In the Game Master content browser, find the DCO commander entity (E_AICommander) and place it. The mod registers it automatically.
  2. Select a group, open its attributes and pick a commander from the DCO Commander dropdown. v0.4.138
  3. Do the same for vehicles you want the commander to use for transport and support.
  4. Set the commander's mode — offensive, defensive or balanced — and its objectives.
  5. Release a group again at any time by clearing the dropdown; it goes back to normal behaviour.
Nothing happening? A commander only controls groups that were assigned to it. Unassigned groups keep doing what they were already doing.

Watch it think

A Game Master-only debug overlay draws what the commander believes: contact reports, threat clusters, the frontline and the thresholds behind each decision. If a threat isn't being answered, the overlay shows which threshold it fell under.

Garrisons Dev build

Garrisoning puts a group inside buildings by slot — windows, rooftops, balconies and doorways — instead of standing around in a room.

  1. Select a group in commanding mode and place the Garrison (DCO) waypoint on a building or position.
  2. Pick the mode: Hold never leaves the building, Defend allows a small flank team outside, Release garrisons until a trigger frees the group.
  3. Tune how it fills: slot share per building, maximum buildings per group, fill order, and whether rooftop slots are allowed.
  4. Set the firing arc weight — 1 puts everyone on windows facing the threat, 0 spreads them 360°.
  5. Set refill delays so slots left by casualties are taken over after a while.

Release triggers

TriggerEffect
Enemy distanceEnemy closer than the set distance frees the group
CasualtiesLosing the set percentage of the garrison frees it
Sustained pressureMost of the garrison pinned for the set time frees it
Re-garrisonOptionally return to the buildings once it's safe again
A debug option draws the slots in use: red for windows, orange for roofs, blue for doors, grey for interior positions.

Tuning AI behaviour

Almost everything is adjustable from the editor, either globally or on a single unit. DCO groups its settings into its own attribute categories.

CategoryCovers
DCO Global SkillSkill, accuracy and aim-improvement time for everyone
DCO Global CombatEngagement behaviour, cover priority, weapon usage
DCO Global ReactionDodging, danger reactions, suppression effect
DCO Global IdleWhat units do with no orders: spreading out, patrols, manning guns
DCO Global Contact SharingHow far and how fast contacts spread between units
DCO Global MedicCross-group medics and casualty handling
DCO Global PlayersHow aware AI is of players and player requests
DCO Unit / Unit Skill / Unit ReactionThe same knobs on one selected unit, including personality
DCO Squad / Squad CommanderSquad tactics, spacing and the squad's own command layer
DCO CommanderCommander mode, assignment and behaviour
DCO Commander Threat / ArtilleryThreat thresholds, fire missions and counter-battery
DCO ObjectiveObjective setup and control
WaypointDCO options on waypoints, including garrison
Global vs per-unit. Global values are copied into each unit when it spawns, so changing a global slider mid-mission only affects AI that spawns afterwards. For units already in the field, use the per-unit attributes.

For server owners

Server settings live in JSON files in your server's profile folder, so you can tune DCO without opening the editor or repacking anything.

The config file v0.4.118

  1. Start the server once with DCO_AI loaded. It writes $profile:DCO/DCO_GlobalConfig.json filled with the current defaults.
  2. Edit the values you care about and restart.
  3. After a mod update that adds new settings, the old file is copied to .bak and only the missing keys are added — your values are kept.

Reading the file can be switched off entirely, in which case the values set in the editor are used as-is. Radio lines and default UI settings have their own files (DCO_Radio.json, DCO_UI.json).

Benchmarking Dev build

A benchmark logger writes run files into a folder in your profile. A TICK line records FPS, live AI per faction, commander and objective state on an interval; a slower interval dumps per-group detail, and optionally each member and every vehicle AI has used. Useful when comparing settings or reporting a performance problem.

Troubleshooting

SymptomCheck
Commander does nothingGroups have to be assigned to it in their attributes. Without an assignment they keep their own behaviour.
Commander dropdown only shows "None"The commander roster hasn't reached this machine yet, or there's no commander for that faction. Place a commander for the same faction as the group.
Global slider changed nothingGlobal values are applied when a unit spawns. Change the per-unit attribute, or respawn the AI.
Server JSON edits ignoredReading the config file can be disabled in the editor; make sure it's on and the path matches.
Feature from the roadmap missingCheck whether it's marked Dev build — those aren't in the public Workshop version yet.
